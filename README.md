A collection of Database Management System (DBMS) lab assignments and practical work, developed as part of the academic curriculum.

It can be useful for:

🎓 Academic DBMS laboratory work

💻 Writing and executing SQL queries

📝 Assignment reference and revision

🧠 Topics Covered

The practical work in this repository focuses on fundamental DBMS concepts such as:

Database creation and management

Relational database concepts

SQL queries

Data Definition Language (DDL)

Data Manipulation Language (DML)

Data retrieval and filtering

Database constraints

Tables and relationships

Practical database operations

The exact topics and experiments may vary depending on the individual lab assignments included in the repository.

🛠️ Technologies

The repository is focused on:

SQL

Relational Database Management Systems (RDBMS)

Database Management System concepts

You can use a compatible SQL database environment such as MySQL, PostgreSQL, Oracle Database, or another RDBMS depending on the requirements of the individual assignment.
